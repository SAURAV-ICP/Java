Title
SneakerEthics: A Web-Based Platform for Ethical Sneaker Retail
Purpose
The SneakerEthics project aims to create a web application that promotes sustainable fashion by enabling users to purchase ethically sourced sneakers while providing transparency into supply chain practices. It addresses the growing demand for ethical consumerism in the footwear industry.
Audience
The intended audience includes environmentally conscious consumers seeking sustainable sneaker options and administrators responsible for managing inventory and orders within an ethical retail framework.
Aims and Objectives
Aim: To develop a functional web system that facilitates ethical sneaker purchases and inventory management.
Objectives:
Implement secure user authentication and role-based access control.
Design a responsive interface for browsing and purchasing sneakers.
Enable administrators to manage sneaker inventory and track orders.
Ensure data integrity through a normalized MySQL database.
List of Features
User registration and login with role-based authentication.
Browse and purchase sneakers with ethical certifications displayed.
Search functionality to find sneakers by name or category.
Admin dashboard for adding, updating, and deleting sneaker inventory.
Order tracking system for user purchases.
About page highlighting the ethical mission of the platform.
